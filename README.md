# PyTorch Learning

A hands-on learning repository for PyTorch and deep learning.

## Roadmap

- [ ] Tensors
- [ ] Tensor operations and broadcasting
- [ ] Autograd and gradients
- [ ] Datasets and DataLoaders
- [ ] Neural networks with `nn.Module`
- [ ] Loss functions and optimizers
- [ ] Training and evaluation loops
- [ ] GPU acceleration with Intel XPU
- [ ] Computer vision and CNNs
- [ ] Transfer learning
- [ ] Model saving and inference

## Philosophy

This repository focuses on **understanding by implementing** rather than collecting tutorial notes.

Each topic will contain:
- concise notes
- self-written experiments
- small practical exercises
- progressively more complete PyTorch implementations

## Environment

- Python 3.12
- PyTorch
- Intel Arc Graphics / XPU
- VS Code

More advanced project work will move into separate production-focused repositories.
